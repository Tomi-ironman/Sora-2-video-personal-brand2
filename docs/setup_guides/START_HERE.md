## 🚨 Common Issues (& Fixes)

**"FFmpeg not found"**
```bash
brew install ffmpeg
```

**"API key error"**
- Check `.env` exists in project root
- Verify no typos in key names
- Make sure no extra spaces

**"No results found"**
- Try broader search terms
- Check provider websites are up
- Test individual providers

**"Test failed"**
```bash
# Get detailed error
python3 test_media_providers.py --verbose
```
