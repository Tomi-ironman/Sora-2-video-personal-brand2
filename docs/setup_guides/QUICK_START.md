## 💡 **Pro Tips:**

### **For Best Results:**
- ✅ Write scripts with **exclamations** and **short punchy lines**
- ✅ Use **power words** (eternal, never, always, timeless, etc.)
- ✅ Keep scripts **under 300 characters** for API reliability
- ✅ Add **multiple videos** to `/Tomi/` for variety

### **Text Emphasis Triggers:**
- ❗ Exclamation marks
- ❓ Questions
- 💪 Power words (eternal, timeless, never, always, etc.)
- 📏 Short phrases (under 50 characters)
